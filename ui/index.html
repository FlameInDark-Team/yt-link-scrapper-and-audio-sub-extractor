🔌 Chrome Scraper Extension Bridge

Direct Ingestion

The bundled Manifest V3 Chrome extension can stream video links directly into this server with 1 click while you browse YouTube!

1
Load Extension in Chrome:

Open chrome://extensions, toggle Developer Mode on, click Load unpacked, and select the folder Yt Scrapper extension.

2
Browse YouTube & Collect:

Click "Start Collecting" in the extension popup and scroll through any feed, search result, or channel.

3
Push Directly to Studio:

Click the "Send to Harvester" button in the extension popup. The links will appear in your Queue instantly!

Direct Webhook API Test

You can also send links to the server via any script or webhook:

curl -X POST http://127.0.0.1:8765/api/links \
  -H "Content-Type: application/json" \
  -d '{"links": ["https://www.youtube.com/watch?v=..."]}'
